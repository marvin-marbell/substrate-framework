# Proposals

Create one directory per candidate campaign from `memory-templates/campaign-proposal.md`. A proposal may add or challenge claims, but it cannot rewrite canonical documentation or declare a prior claim superseded.

Scientific failures remain inside the proposal's append-only attempt record. They cause a new candidate, reformulation, or separately reviewed foundational-revision proposal; they do not count as completion.
