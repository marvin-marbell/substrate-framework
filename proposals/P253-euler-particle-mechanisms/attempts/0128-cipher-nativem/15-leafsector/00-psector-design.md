## 2. Sector definition (P-sector)

**P-sector** = { textures T : (i) T lives in the F-A/F-B-lite model class on
a defect background; (ii) T meets the admission rule §3; (iii) T's
polarized-preparation fluctuations carry the D3/D4 branch where defined }.
Clauses: (i) fixes the class (no cross-model members); (ii) is the gate;
(iii) attaches the fluctuation branch as sector content, not as a second
membership test (a static-persistent texture with undefined polarized
fluctuations is a member with an unbuilt branch, flagged, not excluded).

## 3. Admission rule (measured, never declared)

Candidate T is admitted iff all four banked bars are met on T, before/after
against frozen bars, with the builder/reviewer split honored (builder
demonstrates, tasked reviewer declares — persist-review pattern):
charge-1 texture (linking-type integer + closed-loop zero, κ=0) / finite
constitution (convergent E + declared tail) / mobility (barrier-free reach +
drift tiering) / persistence-with-discrimination (restoration + trivial-die
contrast). Bars are round numbers with headroom (1/2/5% pattern); margins
receipted per candidate. Failure on any conjunct = not a member (no partial
membership — the conjunction IS the sector).
